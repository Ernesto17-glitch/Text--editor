Undo/Redo with two stacks

A text editor where every edit is pushed onto an undo stack. Undo pops the newest edit and pushes it onto a redo stack. The Java source behind it is on the second tab.

Document

Undo stack

Redo stack

The block at the top of each stack is the next one to come off. Making a new edit empties the redo stack, because the undone “future” no longer applies.

UndoRedoDemo.java: compile with javac UndoRedoDemo.java, run with java UndoRedoDemo
